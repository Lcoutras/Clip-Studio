# Music

Put tracks you are allowed to use in these folders (mp3, wav, m4a, ogg, flac):

- `hype/`  - big drops, phonk, EDM. Used for goals, saves and most plays.
- `funny/` - goofy / meme tracks. Used when a clip gets a funny caption.
- `chill/` - lo-fi. Used for smaller plays.

If a folder is empty the tool picks from any folder. Each clip is lined up so the play
lands on the song's drop (found automatically).

Copyright-safe sources: YouTube Audio Library, Pixabay Music, NoCopyrightSounds (NCS),
or a subscription like Epidemic Sound. Commercial songs will get your clips muted or claimed.
