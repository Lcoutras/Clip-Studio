# Refresh research

1. Read `../output/agent/knowledge.md` and `../docs/content-playbook.md` so you know what's already covered.

2. Search the web, sending several searches at once:
   - Rocket League clips trending on TikTok and YouTube Shorts this month: formats, meme templates, caption styles
   - changes to the TikTok, YouTube Shorts and Instagram Reels algorithms or recommendations for gaming creators
   - small gaming creators growing from clips: posting frequency, best times, hashtags in current use
   - Twitch-to-TikTok/Shorts clip strategies for small streamers

   Open the best pages and read them. Prefer platform announcements, creator-economy research, and real channel examples over generic "10 tips" listicles.

3. Update knowledge.md:
   - Under **Trends (dated, with sources)**, add only findings that would change which clips you pick or how you write posts. Date each one, give its source URL, and say how confident you are.
   - Remove trends older than about 3 months unless they're still current.
   - If a finding contradicts the playbook, note the conflict and tell Luke. Don't edit the playbook: it's part of the app and gets replaced on update.

4. Tell Luke the 3-5 most useful changes, in plain words, and how they'll change the clips you queue.
